05 / Условия оплаты

Условия оплаты

Поэтапная оплата

Этап 1 — Первоначальная оплата

50% до начала работы. Работа начинается после подтверждения получения первоначального платежа.

Этап 2 — Оплата по этапам проекта

Для проектов, состоящих из нескольких этапов, оплата производится в соответствии с согласованными контрольными точками проекта.

Пример: 50% — начало проекта · 25% — промежуточный этап · 25% — финальный этап.

Точный график оплаты можно согласовать индивидуально для каждого проекта до начала работ.

Небольшие проекты

Для небольших проектов или отдельных задач может применяться 100% предоплата.

Крупные проекты

Для крупных проектов график оплаты согласовывается индивидуально.

Условия оплаты

Работа выполняется поэтапно в соответствии с согласованным объёмом работ и графиком оплаты. Каждый этап проекта может быть связан с отдельным платежом. Стоимость, состав работ, сроки и график платежей согласовываются до начала соответствующего этапа.

Задержка оплаты

При задержке оплаты выполнение проекта может быть приостановлено до момента получения соответствующего платежа.

Способы оплаты

  • Банковский перевод
  • Международный банковский перевод
  • PayPal
  • Wise
  • Другие согласованные способы оплаты
